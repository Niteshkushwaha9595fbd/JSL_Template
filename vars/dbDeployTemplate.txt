dbDeployTemplate(Map params)

Parameterized Pipeline Template for Database SQL Schema Deployment.

Usage in Jenkinsfile:
  def dbConfig = [
      repoUrl          : 'https://github.com/my-org/my-db-repo.git', // Git Repository URL
      branch           : 'main',                                     // Git Branch (Default: 'main')
      gitCredentialsId : 'git-credentials-id',                       // Optional: Git Credentials ID
      environment      : 'DEV',                                      // Target Env: DEV, QA, PROD
      dbType           : 'mysql',                                    // 'mysql' ya 'postgres'
      dbHost           : '192.168.1.100',                            // Host / IP
      dbPort           : '3306',                                     // Port (3306/5432)
      dbName           : 'my_app_db',                                // Database Name (Required)
      credentialsId    : 'db-credentials-id',                        // Jenkins DB Credentials ID
      sqlFile          : 'schema.sql',                               // SQL file path
      dryRun           : false                                       // Optional (true/false)
  ]
  dbDeployTemplate(dbConfig)

Pipeline Stages included:
1. Stage: Checkout Repository (Clones repoUrl if passed, or checks out current SCM)
2. Stage: Validate Parameters (Checks dbName, credentials, sqlFile existence)
3. Stage: Pre-Deployment Checks (Tests port connectivity to DB host)
4. Stage: Dry-Run & Schema Validation (Runs if dryRun == true)
5. Stage: Deploy SQL Schema (Runs if dryRun == false)
6. Stage: Post-Deployment Verification (Confirms deployment completion)
Post: Success and failure notifications
